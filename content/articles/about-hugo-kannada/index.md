## ಪೀಠಿಕೆ

ನೀವು ಎಂದಾದರೂ ಡೇಟಾಬೇಸ್, ಸರ್ವರ್ ಅಥವಾ ಭಾರೀ CMS ಪ್ಲಾಟ್‌ಫಾರ್ಮ್‌ಗಳ ಜಂಜಾಟವಿಲ್ಲದೆ ವೇಗವಾದ, ಸುರಕ್ಷಿತ ವೆಬ್‌ಸೈಟ್ ನಿರ್ಮಿಸಬೇಕು ಎಂದು ಬಯಸಿದ್ದರೆ, **Hugo** ಬಹುಶಃ ನಿಮಗೆ ಬೇಕಾದದ್ದೇ. Hugo ಒಂದು ಮುಕ್ತ-ಮೂಲ ಸ್ಟ್ಯಾಟಿಕ್ ಸೈಟ್ ಜನರೇಟರ್, Go ಭಾಷೆಯಲ್ಲಿ ಬರೆಯಲ್ಪಟ್ಟಿದ್ದು ಒಂದೇ ವಾಗ್ದಾನದ ಮೇಲೆ ನಿರ್ಮಿಸಲಾಗಿದೆ: **ವೇಗ**.

WordPress ನಂತಹ ಡೈನಾಮಿಕ್ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್‌ಗಳಿಗಿಂತ ಭಿನ್ನವಾಗಿ, Hugo ನಿಮ್ಮ ಸಂಪೂರ್ಣ ಸೈಟ್ ಅನ್ನು — ಪ್ರತಿ ಪುಟ, ಪ್ರತಿ ಪೋಸ್ಟ್ — ಬಿಲ್ಡ್ ಸಮಯದಲ್ಲಿ ಸರಳ HTML ಫೈಲ್‌ಗಳಾಗಿ ನಿರ್ಮಿಸುತ್ತದೆ. ಫಲಿತಾಂಶ ಎಂದರೆ ತಕ್ಷಣ ಲೋಡ್ ಆಗುವ ಸೈಟ್, ಹೋಸ್ಟ್ ಮಾಡಲು ಬಹಳ ಕಡಿಮೆ ವೆಚ್ಚ, ಮತ್ತು ಅಳಿಸಲಾಗದ ಸೈಬರ್ ಭದ್ರತೆ.

<!--more-->

## ಮುಖ್ಯ ಪರಿಕಲ್ಪನೆ

Hugo ಮೂರು ಅಂಶಗಳ ಸಂಯೋಜನೆಯಿಂದ ಕೆಲಸ ಮಾಡುತ್ತದೆ:

**1. ವಿಷಯ (Markdown)**
ನೀವು Markdown ಫೈಲ್‌ಗಳಲ್ಲಿ ನಿಮ್ಮ ಪೋಸ್ಟ್ ಮತ್ತು ಪುಟಗಳನ್ನು ಬರೆಯುತ್ತೀರಿ. ಪ್ರತಿ ಫೈಲ್‌ನ ಮೇಲ್ಭಾಗದಲ್ಲಿ ಒಂದು frontmatter ತಂಡ (TOML ಅಥವಾ YAML ನಲ್ಲಿ) ಶೀರ್ಷಿಕೆ, ದಿನಾಂಕ, ಟ್ಯಾಗ್‌ಗಳು ಮತ್ತು ಡ್ರಾಫ್ಟ್ ಸ್ಥಿತಿಯಂತಹ ಮೆಟಾಡೇಟಾವನ್ನು ಇರಿಸುತ್ತದೆ.

**2. ಟೆಂಪ್ಲೆಟ್‌ಗಳು (HTML + Go templating)**
Hugo, Go ರ `html/template` ಪ್ಯಾಕೇಜ್ ಬಳಸಿ ಲೇಔಟ್‌ಗಳನ್ನು ವ್ಯಾಖ್ಯಾನಿಸುತ್ತದೆ. ಒಂದು ಬೇಸ್ ಟೆಂಪ್ಲೆಟ್ (`baseof.html`) ಹೊರ HTML ಚಿಪ್ಪು ಕೊಡುತ್ತದೆ, ಮತ್ತು ಪ್ರತಿ ಪುಟ ಪ್ರಕಾರ ತನ್ನ `main` ಬ್ಲಾಕ್ ಮಾತ್ರ ವ್ಯಾಖ್ಯಾನಿಸುತ್ತದೆ — ಮಾಡ್ಯೂಲರ್ ಮತ್ತು DRY ರೀತಿಯಲ್ಲಿ.

**3. Hugo Pipes (ಆಸ್ತಿ ಪೈಪ್‌ಲೈನ್)**
CSS ಮತ್ತು JS ಗಾಗಿ, Hugo ಒಂದು ಅಂತರ್ನಿರ್ಮಿತ ಆಸ್ತಿ ಪೈಪ್‌ಲೈನ್ Hugo Pipes ಹೊಂದಿದೆ. ನೀವು SCSS ಬರೆಯಬಹುದು, Hugo ಅದನ್ನು ಸಂಕಲಿಸಿ, ಕಿರಿದಾಗಿಸಿ, fingerprint ಮಾಡುತ್ತದೆ — webpack ಅಥವಾ Gulp ಅಗತ್ಯವಿಲ್ಲ.

ಬಿಲ್ಡ್ ಆಜ್ಞೆ ಸರಳವಾಗಿ:

```bash
hugo
```

Hugo `content/` ನಲ್ಲಿರುವ ಪ್ರತಿ Markdown ಫೈಲ್ ಅನ್ನು ಪ್ರಕ್ರಿಯೆಗೊಳಿಸಿ, `layouts/` ನಿಂದ ಸೂಕ್ತ ಟೆಂಪ್ಲೆಟ್ ಅನ್ವಯಿಸಿ, ಔಟ್‌ಪುಟ್ ಅನ್ನು `public/` ಗೆ ಬರೆಯುತ್ತದೆ — Netlify, Cloudflare Pages, ಅಥವಾ GitHub Pages ನಂತಹ ಯಾವುದೇ ಸ್ಟ್ಯಾಟಿಕ್ ಹೋಸ್ಟ್‌ಗೆ ಡಿಪ್ಲೋಯ್ ಮಾಡಲು ಸಿದ್ಧ.

## Hugo ಬೇರೆ ಜನರೇಟರ್‌ಗಳಿಗಿಂತ ಏಕೆ ಉತ್ತಮ?

| ವೈಶಿಷ್ಟ್ಯ | Hugo | Jekyll | Next.js |
| --- | --- | --- | --- |
| ಬಿಲ್ಡ್ ವೇಗ | ಅತ್ಯಂತ ವೇಗ | ದೊಡ್ಡ ಸೈಟ್‌ಗಳಲ್ಲಿ ನಿಧಾನ | ಮಧ್ಯಮ |
| ಭಾಷೆ | Go (ಒಂದೇ ಬೈನರಿ) | Ruby | Node.js |
| ಅವಲಂಬನೆಗಳು | ಯಾವುದೂ ಇಲ್ಲ | ಅನೇಕ gems | npm ಪ್ಯಾಕೇಜ್‌ಗಳು |
| ಕಲಿಕೆಯ ತೀವ್ರತೆ | ಕಡಿಮೆ–ಮಧ್ಯಮ | ಕಡಿಮೆ | ಮಧ್ಯಮ–ಹೆಚ್ಚು |

Hugo ನ ಒಂದೇ ಬೈನರಿ ವಿತರಣೆ ಎಂದರೆ `hugo` ಎಕ್ಸಿಕ್ಯೂಟೇಬಲ್ ಬಿಟ್ಟರೆ ಬೇರೆ ಏನೂ ಸ್ಥಾಪಿಸಬೇಕಾಗಿಲ್ಲ — ರನ್‌ಟೈಮ್ ಇಲ್ಲ, ಪ್ಯಾಕೇಜ್ ಮ್ಯಾನೇಜರ್ ಇಲ್ಲ.

## ತೀರ್ಮಾನ

Hugo ಒಂದು ಪ್ರಾಯೋಗಿಕ ಮಧ್ಯದ ಸ್ಥಳವನ್ನು ತಲುಪುತ್ತದೆ: ಸಾವಿರಾರು ಪುಟಗಳಿರುವ ದೊಡ್ಡ ಸೈಟ್‌ಗಳಿಗೆ ಸಾಕಷ್ಟು ವೇಗ, ವ್ಯಕ್ತಿಗತ ಬ್ಲಾಗ್‌ಗಳಿಗೆ ಸರಳ, ಮತ್ತು ಸಂಕೀರ್ಣ ವಿಷಯ ರಚನೆಗಳಿಗೆ ಸಾಕಷ್ಟು ನಮ್ಯ. ನೀವು ಕಾರ್ಯಕ್ಷಮತೆ, ಭದ್ರತೆ ಮತ್ತು ಸರಳತೆಯನ್ನು ಬೆಲೆ ನೀಡಿದರೆ, ಇದು ಯಾವುದೇ ವಿಷಯ-ಆಧಾರಿತ ವೆಬ್‌ಸೈಟ್‌ಗೆ ಅತ್ಯುತ್ತಮ ಅಡಿಪಾಯ.

ಮುಂದಿನ ಲೇಖನದಲ್ಲಿ, ವಿಷಯ ವಿಭಾಗಗಳನ್ನು ಹೇಗೆ ರಚಿಸಬೇಕು, ಟ್ಯಾಗ್‌ಗಳು ಮತ್ತು ವರ್ಗಗಳಂತಹ ಟ್ಯಾಕ್ಸಾನಮಿಗಳನ್ನು ಹೇಗೆ ಬಳಸಬೇಕು, ಮತ್ತು ಐದೇ ನಿಮಿಷಗಳಲ್ಲಿ Netlify ಗೆ ಡಿಪ್ಲೋಯ್ ಮಾಡುವ ಬಗ್ಗೆ ನೋಡೋಣ.
